# OAuth 2.0 и JWT ранливости

Главниот елаборат е [`elaborat-oauth-jwt.html`](elaborat-oauth-jwt.html). HTML датотеката е самостојна и може да се отвори без интернет-врска. Изворниот текст е во [`elaborat-oauth-jwt.md`](elaborat-oauth-jwt.md).

Во проектот има две одвоени лаборатории:

- `lab/oauth-csrf/` — OAuth Login CSRF со ранлив и заштитен callback;
- `lab/jwt/` — три JWT сценарија (`alg: none`, слаба HMAC тајна, RS256→HS256).

Секој дел од елаборатот ги содржи условите, чекорите за стартување, очекуваните резултати и бришењето на околината. Лабораториите се намерно ранливи и се наменети само за локална употреба.

За повторно генерирање на заедничкиот HTML по измени во `oauth2-elaborat.md` или `jwt-elaborat.md`:

```bash
npm ci
npm run build:combined
```

За стариот, само OAuth документ: `npm run build:html`. Пред предавање треба да се внесе името и индексот на коавторот на насловната страница; изворното место за тоа е во `scripts/build-combined.mjs`.
