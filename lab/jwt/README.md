# JWT лабораторија

Ова е намерно ранлива локална апликација за три JWT сценарија. Не користете ја на јавна мрежа.

```bash
docker compose up --build -d
python3 attacks.py all
docker compose down --rmi local
```

Во средната команда треба да се видат три прифаќања (`HTTP 200`) на ранливите проверки и три одбивања (`HTTP 401`) на соодветните заштитени проверки. Деталното објаснување е во секциите 3–4 од `elaborat-oauth-jwt.html` во коренот на проектот.
