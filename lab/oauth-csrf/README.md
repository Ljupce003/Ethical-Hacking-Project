# OAuth Login CSRF лабораторија

Ова е намерно ранлива, целосно локална лабораторија за демонстрација на OAuth Login CSRF предизвикан од недостасувачкиот параметар `state`.

## Компоненти

- `http://localhost:9000` — локален OAuth Authorization Server;
- `http://localhost:8000` — клиентска апликација за приватни белешки;
- `http://127.0.0.1:7000` — страница под контрола на напаѓачот.

Сервисите се достапни само преку loopback-интерфејсот `127.0.0.1` и не треба да се изложуваат на локалната мрежа или на интернет. Различните имиња `localhost` и `127.0.0.1` се користат за клиентот и страницата на напаѓачот, бидејќи browser cookies се раздвојуваат според host, но не според TCP-порта.

## Стартување

Од овој директориум изврши:

```bash
docker compose up --build
```

Потоа отвори `http://127.0.0.1:7000` и следи ги чекорите на екранот.

## Запирање и бришење

Притисни `Ctrl+C`, а потоа изврши:

```bash
docker compose down --rmi local
```

Сите корисници, authorization codes, access tokens, сесии и белешки се чуваат само во меморија и исчезнуваат кога контејнерите ќе се запрат.
